# 接口与参数发现

## 前端不是事实来源

前端 JS 里的请求形状（路径、方法、**参数名**）经常和服务端不一致，因为：

- 后端改过名，前端没同步（历史遗留）
- 前端只是"演示版"，真实客户端是另一套
- 出题人故意用错误的前端误导

**判定方法**：服务端返回**固定错误串**（`{"error":"URL is required"}` / `参数缺失` / `Invalid request`），
说明它在找一个你不认识的键。这时不要判"接口坏了"，去做参数名爆破。

## 参数名爆破

```
paramfuzz(url=接口, baseline="固定错误串")                 # body/JSON
paramfuzz(url=接口, location="query", baseline=...)       # query
paramfuzz(url=接口, location="form",  baseline=...)       # 表单
paramfuzz(url=接口, value="1",        baseline=...)       # 换值：参数存在但值被校验
```

引擎行为：热门词优先 → 命中即停 → 报告状态码/长度/响应片段。
判定不是"完全相等"，而是 **状态码变 / 特征串消失 / 长度差 > 40B**。

## 端点发现

- 形状优先于字典：`/api/<资源>/<动作>`、`/api/v1/<资源>`、`/admin/<动作>`、`/<资源>/<id>`
- 从首页 JS 里抓所有 `fetch(` / `axios.` / `$.ajax` 的路径，通常就够
- 405 列表 = 待打的 POST 接口清单
- 401 列表 = 有权限就能读的清单（拿到 token 后回来）

## 参数名拿到之后

按**值类型**分流（这一步决定用哪张技术卡）：

| 值的形状 | 可能的洞 |
|---|---|
| URL / 域名 | SSRF、开放重定向、XXE 外部实体 |
| 文件名 / 路径 | 路径穿越、任意文件读、任意文件写 |
| 被拼进命令 | 命令注入（试 `;` `|` `$()` 反引号 换行） |
| 被拼进 SQL | 注入（先测单引号是否 500/报错） |
| 被当模板渲染 | SSTI（`{{7*7}}` `${7*7}` `<%= 7*7 %>`） |
| 数字 / UUID | IDOR、越权（枚举相邻值） |
| 被反序列化 | 反序列化（看 Content-Type / cookie 格式） |
