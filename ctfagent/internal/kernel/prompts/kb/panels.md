# 管理面板 / AI 控制台：入口 → 登录 → 用面板自己的能力拿文件

这类目标（运维面板、容器面板、AI 工作台、模型调试台）通常**不需要挖漏洞**：
它们的正常功能就是「在服务器上执行命令 / 读写任意文件」。门槛只在三件事：
**进得去、过得去验证码、找对接口**。

## 一、先过「安全入口」

不少面板支持把后台藏在一个随机路径后面（"entrance" / "安全入口" / "隐藏入口"）。

- 入口码在请求里通常**不是明文**：常见做法是把入口码 **base64** 后放在一个头里
  （例如 `EntranceCode: <base64>`），服务端解出来跟配置比对。
- **验证码与入口常常联动**：带「跳过验证码」开关的请求会**额外**要求正确入口码；
  走正常验证码流程时反而不校验入口。所以顺序是：
  1. 先取验证码 → 识别 → 带着 captchaID + 答案登录（这一步先确认账号密码对不对）；
  2. 若密码正确但报「入口错误」，说明只差入口码；入口码常见就是文档/默认部署里的固定串
     （`entrance`、`admin`、`panel` 之类），**先试默认值，再去想绕过**。
- 验证码是一次性的，取图和提交要连在一起做；图片是纯字符/算式的话直接看图转录即可。

## 二、登录后第一件事：找「文件接口」

登录后**不要急着写 webshell / 计划任务**。面板的文件管理 API 往往直接就能读任意路径：

- 典型接口形态：`POST /api/.../files/content`（读文本）、`files/search`（列条目）、`files/save`（写文件）。
- 参数名从**前端 bundle** 里找（搜 `files/`、`content`、`search` 等字样），
  或者直接按「列表/读取/保存/重命名/下载」这五类各试一次。
- 一次调用就能读到目标路径 → 直接结束，别浪费时间做 getshell。

## 三、拿不到文件接口时的执行面

| 执行面 | 说明 |
|---|---|
| 计划任务 / 定时脚本 | 多数面板允许写 shell 任务；`* * * * *` 或「立即执行」按钮 |
| 终端 WebSocket | `/hosts/terminal`、`/containers/exec` 之类，多为 WS + base64 帧 |
| 站点 / 容器 / 数据库配置 | 改启动参数、挂载、命令前缀 |
| 备份 / 导入导出 | 导出到可下载目录，再从下载接口取 |

**写文件时优先写「面板自己会加载的路径」**：插件文件夹、启动脚本文件夹、模板与静态资源位置。

## 四、配置注入 → 重启 → 启动钩子（通用链）

当面板/AI 服务有「设置项 → 写配置文件 → 重启生效」这条链时：

1. 找**能改配置的未授权接口**。常见是「模式/策略」这类看起来无害的开关，
   实现里直接把 query 参数写进 `key = value` 形式的配置文件；
2. 参数值里注入**换行/回车**（`%0D` / `%0A`）就能追加任意配置项
   （配置解析器通常是「后出现的键覆盖先出现的」，追加在文件末尾即可覆盖）；
3. 重启（服务自带的 reboot/restart 接口）让新配置生效；
4. 让新配置指向**启动时会被执行的清单文件**（启动脚本列表、插件列表、开机任务）。

这条链不需要目标出网，也不需要你会写代码 —— 只要有「写配置 + 触发重启」两点。

## 五、几类常见 AI 工作台的通用入口

- **Gradio 类**：组件服务器接口能把**任意路径**塞进组件缓存（`move_resource_to_block_cache` 之类），
  再按返回的缓存路径用文件下载接口取回 → 任意文件读。
  直接的文件接口通常有白名单目录，绕过点是「先缓存、再读缓存」。
- **ComfyUI 类**：有「用户数据目录」读写接口（`userdata` / `user`），
  能列路径、读文件、**写文件**；安装/更新类接口受「安全等级」限制，
  而安全等级来自配置文件（可被上面的 CRLF 注入改写）→ 重启后放开。
  启动时会执行「启动脚本清单」里的命令，这是最稳的落地点。
- **Jupyter 类**：`/api/contents` 直接读写任意路径；`/api/kernels` 起内核跑代码。
- **模型调试台（Langflow / Flowise / Dify 类）**：优先找
  「代码校验 / 试运行 / 自定义组件 / 函数节点」这类**会 eval 用户代码**的接口，
  一个 `@exec(...)` 或函数节点的默认参数就能执行；返回体常把 `stderr` 原样回显，直接当回显通道。

## 六、顺序清单

1. 扫端口（面板常同时开 SSH/终端端口）→ 2. 首页标题与版本 → 3. 默认凭据 →
4. 验证码 + 入口码 → 5. 登录后先找文件读写接口 → 6. 文件接口不行再找执行面 →
7. 有「设置+重启」链就走启动钩子。
